# Sistema de Gerenciamento de Pedidos

## Descrição
Projeto desenvolvido em Java puro para demonstrar na prática os conceitos de Design Patterns (Padrões de Projeto).

## Funcionalidades
- Cadastro de pedidos.
- Validação de pedidos.
- Pagamento via PIX.
- Pagamento via cartão.
- Processamento de pedidos.

## Padrões de Projeto utilizados

### Strategy
Permite utilizar diferentes formas de pagamento.

### Factory
Responsável pela criação dos objetos de pagamento.

### Chain of Responsibility
Realiza as validações dos pedidos em sequência.

### Facade
Simplifica o processamento dos pedidos.

## Tecnologias utilizadas
- Java
- Programação Orientada a Objetos

## Objetivo
Aplicar na prática os conhecimentos adquiridos sobre Design Patterns, desenvolvendo um sistema organizado e de fácil manutenção.
